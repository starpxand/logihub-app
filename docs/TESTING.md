переключаясь между ролями так же, как это делают пользователи. Статус заказа после каждого шага сверяется
с хранилищем приложения.

```text

```

## 2. Ручная проверка

- Все экраны пяти ролей просмотрены на ширине 1440, 1366 и 390 px (телефон).
- Документы (договор-счёт, ТТН, маршрутный лист, акт, претензия) выводятся на печать и сохраняются в PDF.
- PWA устанавливается из браузера и открывается без сети (service worker кэширует оболочку и данные).
- APK установлен на телефон Xiaomi Redmi (Android 10, 1080×2340): вход по ролям, экран водителя, карта, маршрутный лист и кнопки действий работают; приложение открывается без сети.

## 3. Обнаруженные проблемы и решения

| Проблема | Причина | Решение |
|---|---|---|
| При открытии страницы «Уведомления» вкладка зависала (`Maximum call stack size exceeded`) | отметка «прочитано» сохраняла состояние и вызывала перерисовку, перерисовка снова отмечала прочитанное | отметка прочитанного сохраняется без перерисовки (`save(silent)`) |
| Меню уведомлений закрывалось сразу после открытия | та же перерисовка после отметки прочитанного | то же исправление; точка-счётчик убирается вручную |
| На телефоне не было видно логотипа в шапке | градиент логотипа ссылался на `id` внутри скрытой боковой панели | у каждого экземпляра логотипа свой `id` градиента |
| На экране водителя появлялась горизонтальная прокрутка | длинные подписи кнопок раздвигали колонку сетки | `minmax(0, 1fr)` для колонки, перенос текста в кнопках |
| Поля формы заявки выходили за край на телефоне | поле с иконкой имело `width: 100%` рядом с иконкой | поле внутри обёртки – `flex: 1; min-width: 0` |
| На карте Хабаровск оказался на побережье | береговая линия была нарисована приблизительно | побережье, Сахалин и Амур построены по реальным координатам в той же проекции, что и города |
| Прогноз прибытия показывал «00:00» | срок доставки считался по дате без времени | плановое время прибытия – конец окна доставки клиента |
| На телефоне (Redmi, Android 10) экран входа шире экрана | неразрывная подпись роли («Склад № 1, Комсомольск-на-Амуре») раздвигала колонку сетки; системный крупный шрифт MIUI увеличивал текст в WebView | `minmax(0, 1fr)` для колонок экрана входа, в APK масштаб текста зафиксирован на 100 %; тест 13 проверяет и экран входа |
| Верхняя панель «сжималась» по высоте на длинных страницах (ПК и телефон) | панель – элемент гибкой колонки с прокруткой, браузер ужимал её, когда содержимое длиннее экрана | элементы колонки не сжимаются (`flex: none`) |
| На телефоне нельзя было выйти или сменить роль | кнопка выхода была только в боковой панели, скрытой на телефоне | вкладка «Ещё» – профиль, смена роли, выход, уведомления, процесс; аватар в шапке открывает её |
| «Назад» в APK перебирал все посещённые страницы | WebView шёл по истории переходов | «назад»: закрыть окно → главный экран роли → выход из приложения (`window.logihubBack`) |
| На телефоне форма заявки шире экрана | скрытые радиокнопки категорий груза позиционировались относительно карточки и наследовали ширину 100 % | подпись-чип – контекст позиционирования, радиокнопка 1×1 px |
| Тест не мог выбрать категорию груза | радиокнопки скрыты визуально, клик приходится на подпись | тест кликает по подписи, как пользователь |
